# Divya Gupta — Personal Portfolio

A personal portfolio website exploring AI, cognition, product, research and the systems I build.

## What this project is

This repository contains the source code for my personal portfolio. It is intentionally dependency-free HTML/CSS/JavaScript so the site can be deployed directly with GitHub Pages.

The portfolio is designed to show more than a résumé: selected technical/product work, research interests, the way I think about AI reliability, and the broader questions that motivate my work.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive layout
- GitHub Pages
- No external framework or build step

## Case studies

The project pages are deliberately generalized. They describe problem-solving approaches without exposing client names, proprietary files, internal prompts, credentials, private URLs or confidential outputs.

## Deployment

GitHub Pages can be enabled from **Settings → Pages → Deploy from branch → `main` / root**.

## Development philosophy

The portfolio is itself an ongoing project. Future iterations will improve the visual system, accessibility, case-study depth, technical demonstrations, research writing and deployment workflow.

## Privacy / confidentiality

Do not commit confidential client or employer information, private screenshots, credentials, proprietary source code, private URLs or other non-public material.
