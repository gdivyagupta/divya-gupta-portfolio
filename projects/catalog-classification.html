CASE STUDY / 03

Catalog Classification

Turning messy product descriptions into useful, structured decisions.

PROBLEM

Real-world categories are rarely clean.

Product catalogs contain inconsistent names, overlapping categories, missing attributes and language that changes by seller. A useful classification system has to handle ambiguity rather than pretending it doesn't exist.

This case study examines a practical pipeline: schema design, normalization, model-assisted classification, confidence scoring and human review.

DESIGN

Define the taxonomy before choosing the model.

Use confidence thresholds to route uncertain cases.

Preserve the original text alongside normalized fields.

Make human review part of the system, not a failure state.
